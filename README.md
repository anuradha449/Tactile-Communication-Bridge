# 🤟 Tactile Communication Bridge

A Streamlit-based AI + Computer Vision application that converts Braille images into readable text and speech.

This project helps bridge communication between visually impaired individuals and non-Braille readers using image processing, analytics, and text-to-speech technology.

---

# 📌 Features

✅ Upload Braille images  
✅ Detect Braille dots using OpenCV  
✅ Translate Braille patterns into English text  
✅ Generate speech output using gTTS  
✅ View translation analytics  
✅ Character frequency analysis  
✅ Word distribution analysis  
✅ Download CSV reports  
✅ Download TXT reports  
✅ Modern responsive Streamlit UI
